# GTT Center Perth

**WA's first premium waiting experience for pregnant women undergoing the Glucose Tolerance Test.**

Pregnant women spend up to 3 hours at pathology for the GTT (Gestational Diabetes Test). GTT Center Perth transforms that wait into a restorative experience: massage, nails, hair, and 3D keepsake ultrasound — all under one roof.

## Model

**Corrected 2026-08-08 — this section previously described a sublet/subtenant model that is no longer current; see `docs/01_conflicts_log.md` CONFLICT-04 and `docs/architecture/REPOSITORY-AUDIT.md` finding F-1.**

- **Pathology:** Partner with WDP (priority 1, outreach in progress) / PathWest / Clinipath for on-site blood collection — Licensed Collection Centre model, no NATA accreditation required for GTT Center Perth itself
- **Services:** Employed staff (casual/permanent) deliver massage, nails, hair, and beauty — **not subtenants.** GTT Center Perth pays wages, not room rent
- **3D Scan:** Not part of current launch scope — a possible future/Phase 2 addition only. Never framed as diagnostic; keepsake/entertainment only if it is ever added
- **Entity:** YETI Holding Trust
