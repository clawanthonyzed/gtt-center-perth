## 1. Parking — CHECK FIRST, BEFORE ANYTHING ELSE

*Source: `docs/location-scouting.md`'s own non-negotiable rule — "do NOT view any property without first confirming parking count."*

- [ ] Dedicated off-street spaces: _____ (need **minimum 8–10**)
- [ ] OR free public parking within 50m, if dedicated count is short: _____ spaces
- [ ] Well-lit for 7:30am winter arrivals? Y / N
- [ ] Wide, pram-accessible spaces (no gravel)? Y / N
- [ ] 3–5 additional spaces for staff? Y / N

**If parking fails this check, stop here — do not proceed with the rest of the inspection unless the property is otherwise exceptional and parking is genuinely negotiable (e.g. an adjacent lot).**

## 3. Size & Layout — Quick Fit Check

*Source: `docs/floor-plan-concept.md`, `docs/architecture/VENUE-ACQUISITION-DUE-DILIGENCE.md` §1.3.*

- [ ] Usable floor area: _____ sqm
  - Below 239sqm → real compromise against the current committed layout, flag it
  - 239–262sqm → fits day-one operations, tight-to-comfortable growth margin
  - Above 262sqm → comfortable, check rent scales sensibly
- [ ] Ceiling height / general shape suitable for an open-plan lounge + 2 nail stations + 2–4 hair chairs zone
- [ ] Room/nook big enough for ONE fully enclosed room (Blood Collection Room, ~18sqm, needs solid walls + a door) — **this is the one room that cannot be curtain-partitioned**
- [ ] Space for 2–4 curtain-partitioned bays (Massage/Facial-Beauty) — curtains only, no walls needed here
- [ ] Existing internal walls: how many, and do they help or hinder the above layout?
- [ ] Prior tenancy use: _______________________ (former health/medical/beauty fit-out = real cost saving, flag it)

## 4. Wet Areas & Building Services

*Source: `docs/floor-plan-concept.md` Critical Design Requirements; `docs/architecture/startup-cost-reconstruction.md` Category C.*

## 5. Rent & Commercial Terms — Do the Maths On the Spot

*Source: `docs/rent-budget-2026-07-28.md` — compare against the A$96,000/year true-occupancy-cost budget, not a bare headline rent figure.*

- [ ] Face rent: $_____ /sqm/yr OR $_____ /month
- [ ] Outgoings: [ ] Included in face rent  [ ] Additional, $_____ /sqm/yr — **ask explicitly, don't assume**
- [ ] GST: exclusive of the above? Y / N
- [ ] Car bay fees, if separate: $_____ /bay/month × _____ bays
- **True occupancy cost (rent + outgoings + car bays, before GST):** $_____ /yr → **compare against A$96,000/yr budget**
- [ ] Lease length offered: _____ (target: 3yr + 3yr option)
- [ ] Bond: _____ months' rent
- [ ] Rent-free/incentive period offered: _____ (target: 3–6 months during fit-out)
- [ ] Landlord fit-out contribution offered? Y / N — amount: $_____ (a real negotiation lever, not assumed)

## 7. Pathology / WDP Suitability

*Source: `docs/location-scouting.md`'s own explicit rule — WDP collection-room spec must be obtained BEFORE signing any lease. Also see `docs/architecture/WDP-COMMERCIAL-ALIGNMENT-REVIEW.md`.*

- [ ] A room (or space that can become one) meeting WDP/NPAAC's collection-centre spec: private, solid walls, ≥10sqm, room for 2 phlebotomy chairs + a vasovagal recovery chair/couch, clinical sink, sharps storage
- [ ] Proximity to the lounge/waiting area (short walk for the phlebotomist, per the design's own "3 steps to client" principle)
- [ ] Distance/drive-time to WDP's specimen-processing lab — relevant to whether the conditional overnight-storage option is realistically usable
- [ ] **Reminder: WDP has NOT yet been told this venture's current 18-client/day committed volume in any confirmed-sent communication — this remains open regardless of which venue is chosen (see `docs/architecture/WDP-COMMERCIAL-ALIGNMENT-REVIEW.md`)**
