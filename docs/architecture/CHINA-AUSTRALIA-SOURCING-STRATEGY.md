## 2. Station/Room Program Investigation — Evidence, Not a Guess

### 2.1 The Question

Round 1 flagged, but did not investigate, why the fit-out brief's own station program (2 Blood Collection Rooms, 3 Massage + 4 Beauty, 4 Nail + 4 Pedicure) differs from the currently-costed model (1 room/2 chairs, 4 combined Massage+Beauty rooms, 4 nail stations already including pedicure chairs). ### 2.2 Blood Collection Rooms — No Repo Evidence for a Second ROOM; Real Evidence for a 3rd CHAIR

**Finding:** the repository has an extensive, well-documented, partially-verified growth-capacity path for the Blood Collection function — **Scenario D**, adding a **3rd phlebotomy chair inside the existing single room** to reach 15 clients/day (`docs/scenario-d-investigation.md`, `docs/am-capacity-weekend.md`, `docs/business-plan.md` §33, `outputs/master-dossier-v2/index.html` Chapter 33/34). This is real, substantial, cross-referenced material — not a passing mention.

**What this evidence does NOT support:** nowhere in this repository — not in `scenario-d-investigation.md`, not in `am-capacity-weekend.md`, not in `floor-plan-concept.md`, not in any staffing or financial document — is a **second physical room** proposed for blood collection. Every reference to growth capacity in this function describes adding chairs to the one room, never adding a room. `floor-plan-concept.md`'s own design principle states "Collection room is adjacent to lounge — phlebotomist walks 3 steps to client" (§Design Principles) — a single-room model is load-bearing to that stated efficiency logic, not incidental.

**Two interpretations, neither resolved by this repository's evidence:**
- **Interpretation A (more likely, given the evidence): a miscommunication/shorthand for wanting more phlebotomy capacity** — which the venture already has a real, documented, partially-verified lever for (Scenario D's 3rd chair), just expressed as "2 rooms" rather than "a 3rd chair." If this is the intent, the existing Scenario D work (already verified schedule, already-costed 3rd-phlebotomist wage line, already-identified WDP cutoff dependency) is the correct basis to build from — not a fresh 2nd-room concept.
- **Interpretation B (genuinely new, no repo precedent): an actual second physical room** — for a reason not previously modelled (e.g. physical separation for privacy/observation, provision for a second, unrelated future clinical use, or simple headroom). **No document in this repository evaluates this idea at all** — not costed, not scheduled, not staffed, not requested anywhere before this fit-out brief.

**FOUNDER DECISION required, not resolved here:** which interpretation is correct. If A, this reduces to activating the already-substantially-researched Scenario D (which itself remains gated on the still-open WDP specimen-cutoff/window confirmation for the 15-client schedule, per `docs/operations-manual.md` line 400 — **THIRD-PARTY DEPENDENCY**, not a new finding). If B, this is a genuinely new design question requiring fresh floor-area, cost, and staffing work not yet begun anywhere.

## 5. Three Procurement Models — Compared, With a Labelled Recommendation

### Model A — Direct-to-Manufacturer (e.g. contacting XERA Display or Brutalist Store Display Products directly)

| Factor | Assessment |
|---|---|
| Purchase price | Lowest theoretical unit price — no agent margin |
| QC | Entirely dependent on the manufacturer's own self-reported QC, or requires GTT/Anthony to separately engage an independent inspector (§3.2's QIMA/SGS/Bureau Veritas category) |
| Communication/design interpretation | Highest risk — no intermediary to translate the brief's brand language (§2 of the design brief, the locked 7-colour palette, the material restraint principle) into terms a factory's own sales team reliably executes without drift |
| Manufacturing mistakes | Full risk sits with GTT/Anthony to catch (via the manufacturer's own photos/samples) and resolve (via the manufacturer's own goodwill, since no agent is contractually holding them accountable) |
| Shipping/customs/GST | Falls to GTT/Anthony to coordinate directly, or to a separately-engaged freight forwarder (already-known Perth options: DB Schenker, Toll Global Forwarding, per `docs/hire-purchase-china.md` §6) |
| Warranty/replacement parts | Direct relationship with the factory — can be faster if the relationship is good, but no independent party advocating for GTT if the factory is slow/unresponsive |
| Founder time required | **Highest** — Anthony personally becomes the project manager, QC coordinator, and dispute-resolution party |
| Suitability for a premium venue | **Real risk** — the entire brief's design-language discipline (§2 of the fit-out brief) depends on consistent interpretation across many item categories; a single manufacturer's sales team, without an intermediary checking output against the brief, is the highest-risk path for the finished venue reading as generic rather than considered |

### Model B — Independent Sourcing Agent (e.g. Epic Sourcing Australia or a China-based FF&E agent like FBM Sourcing)

| Factor | Assessment |
|---|---|
| Purchase price | Higher than Model A on a per-item basis (agent fee, typically 3-10% commission or a flat project fee per §3.2's research) — but this fee buys design-interpretation, QC, and dispute-resolution capacity Model A doesn't have |
| QC | Structured, professional process (per §3.2's 3-checkpoint findings) — a real, evidenced improvement over Model A |
| Communication/design interpretation | An Australian-based agent (Epic Sourcing) genuinely reduces this risk — same time zone, same design-brief language fluency; a China-based agent (FBM) reduces it less, though still more than no intermediary at all |
| Manufacturing mistakes | The agent has a commercial incentive to catch and fix mistakes before shipment, since their own reputation/repeat business depends on it — a real, structural improvement over Model A |
| Shipping/customs/GST | Typically bundled into the agent's service, per §3.2's findings (Epic Sourcing's own site claims quality/shipping coordination) |
| Warranty/replacement parts | An ongoing agent relationship gives GTT a single accountable party to escalate to, rather than negotiating directly with an individual factory each time |
| Founder time required | Materially lower than Model A — the agent absorbs day-to-day coordination |
| Suitability for a premium venue | **Better than Model A** for the same reason it costs more — a professional intermediary is structurally better positioned to hold multiple factories to one consistent design/material standard across the whole venue, which is exactly what this brief's own restraint-and-consistency brand principle depends on |
| Genuine limitation, not glossed over | No sourcing agent researched this round — Australian or China-based — has any claimed capability, and none should be assumed to have any capability, in Australian clinical, electrical, building, or accessibility compliance. This limitation applies to every model, but is worth restating specifically here since Model B's professionalism could otherwise create a false impression of broader regulatory competence |

### Model C — Hybrid (Agent for China-sourceable categories; Australian-sourced/locally-managed for clinical/regulated/safety-critical/Australia-specific items) — **Recommended, and this round takes it seriously as instructed**

| Factor | Assessment |
|---|---|
| Purchase price | Captures most of Model A's cost advantage on the genuinely China-suitable categories (Category A/B items per the design brief's §21, restated and stress-tested in §6 below), while avoiding any cost-saving pressure on the categories where the real cost of failure (a mid-operation clinical-chair failure, an uncertified electrical fitting) far exceeds any purchase-price saving |
| QC | Applies the Model B structured QC process specifically to the categories where an agent adds the most value (multi-item, design-consistency-dependent categories: joinery, cabinetry, styling stations), while keeping the highest-risk categories (phlebotomy chairs, clinical-adjacent items) inside the existing, already-established Australian-sourcing decision (`docs/hire-purchase-china.md` §1A, `docs/architecture/CHINA-ASIA-SUPPLIER-FEASIBILITY.md` §1) — this brief does not disturb that already-conservative decision |
| Communication/design interpretation | The Australian-sourced/locally-managed items (reception counter build, clinical fit-out, electrical/plumbing installation) are inherently handled by local trades who already speak the brief's language and are accountable under Australian consumer/trade law — removing the highest-stakes items from the cross-border communication risk entirely |
| Manufacturing mistakes | Confined to the lower-stakes category (a wrongly-finished cabinet is a real but recoverable problem; a wrongly-certified clinical chair is not) |
| Shipping/customs/GST | Same as Model B for the China-sourced portion; not applicable to the Australian-sourced/local-trade portion |
| Warranty/replacement parts | The highest-criticality items (phlebotomy chairs, AED, fire/life-safety equipment) keep the strongest, most direct Australian warranty/service pathway; lower-criticality items accept a longer, agent-mediated pathway in exchange for cost savings — a deliberate, disclosed trade-off, not an oversight |
| Founder time required | Lower than Model A, comparable to Model B for the China-sourced portion, plus the existing local-trades coordination this venture already needs regardless of any sourcing decision (fit-out construction, electrical, plumbing) |
| IP/design protection, ability to change after manufacture | Splitting the project this way also limits how much of the total venue design is exposed to any single supplier relationship — a genuine, if secondary, risk-diversification benefit |
| Responsibility if something arrives wrong | Clearly allocated per category, rather than blurred across one all-or-nothing supplier relationship |
| Suitability for a premium/luxury venue | **Best fit of the three, on the evidence available** — it is the only model that doesn't force a single trade-off between cost and quality/compliance across the entire project; it applies the right tool to each category |

### Recommendation — Labelled Clearly, Not a Founder Decision

**This document recommends Model C (Hybrid), specifically an Australian-based sourcing agent with demonstrated commercial-furniture/hospitality experience (Epic Sourcing Australia is the strongest evidenced candidate found this round, though not the only possible one) engaged for the China-sourceable, design-consistency-dependent categories, combined with independent third-party pre-shipment inspection (§3.2's QIMA/SGS/Bureau Veritas category) as a standing check regardless of which agent or manufacturer is ultimately used, and Australian local-trade/local-supplier sourcing retained unchanged for every clinical, regulated, or safety-critical category.** This is a recommendation only — Anthony has not been asked to, and has not, decided this; no agent has been contacted or engaged.

## 10. Could a Sourcing Agent Be a Full Project Partner?

**Finding:** based on the evidence gathered this round, **Epic Sourcing Australia is the closest candidate found to an end-to-end capable partner** — Australian-based (removing the cross-border communication/accountability gap), furniture-specialised, custom-manufacture capable, with an explicit hospitality-sector claim and in-house QC/factory-audit capability. **This is not independently verified beyond their own website** — no third-party client review, case study, or reference project specific to a salon/wellness/medical-adjacent venue was found this round. FBM Sourcing shows deeper hospitality-FF&E-specific evidence but is China-based, which materially changes the accountability/communication risk profile (§3.2).

**Engagement type, if pursued:** based on what an agent of this kind can plausibly do, the right engagement type is closest to **"procurement management" or "design-to-manufacture coordination" for the China-sourceable category only** (per Model C, §5) — not "turnkey furniture-fitout procurement" for the whole venue, and never "full project management" of the venue overall, which would improperly bundle Australian compliance-critical work into a commercial-furniture-agent relationship.

**Hard boundary, restated because it matters more here than anywhere else in this document:** **no sourcing agent — Australian or China-based, however capable — should be assumed to have any legal authority or genuine competence to perform Australian architectural, engineering, building-certification, or regulated-clinical-design work.** Every agent researched this round is a furniture/fixture sourcing and manufacturing-coordination specialist. That work stays with Australian licensed professionals (architect, engineer, electrician, plumber, LEV/HVAC contractor, WDP) regardless of which procurement model is chosen. This is not a new finding — it is the same boundary the original fit-out brief already drew (§0/§30), restated here because the "full project partner" framing in this round's brief specifically risks blurring it if not restated explicitly.

## 11. Recommended Staged Procurement Pathway — Refined From Anthony's 15-Stage Sketch

Reordered and adjusted based on this round's research, with the reasoning for each change stated:

1. **Lock the station/room program** (§2 above) — genuinely has to come first; every downstream step (floor area, cost, agent scoping) depends on it.
2. **Select the venue** — already the venture's own established single most consequential dependency (`docs/VERIFICATION-TRACKER.md` item 3, BLOCKING; `outputs/master-dossier-v2/index.html` Chapter 35's own execution-roadmap finding). No change to this sequencing — it was already correctly sequenced early in Anthony's own sketch.
3. **Measure/survey the confirmed venue.**
4. **Australian compliance review** (architect/access consultant, electrician, plumber, LEV/HVAC contractor, WDP room sign-off) — **this round's research reinforces keeping this step before, not after, supplier engagement**, since §9 shows several "Founder decision required" and "Professional verification required" items directly change what would be quoted.
5. **Finalise room-by-room design** against the now-confirmed program and venue.
6. **Classify every item China/Australia/either** — this document's §6 stress-tested matrix is the starting reference, refined against the actual final item list once step 5 is complete.
7. **Obtain Australian benchmark pricing first, not last** — **a genuine sequencing improvement over Anthony's original sketch, worth flagging explicitly:** Anthony's sketch placed "Australian benchmark pricing" before "China factory pricing," which this research agrees with — a landed-cost comparison is meaningless without a real Australian benchmark to compare against, and several categories (Lounge seating, phlebotomy chairs) are already expected to stay Australian regardless, so their benchmark pricing is not wasted effort either way.
8. **Approach a sourcing agent for an exploratory, no-commitment scoping conversation** (per this document's Model C recommendation) — **sequenced before requesting individual factory pricing**, not after, since an agent's own scoping process typically identifies which factories are worth quoting in the first place, avoiding wasted direct-factory outreach on categories an agent would advise against importing at all.
9. **Obtain China factory/agent pricing** (via the agent relationship from step 8, using the RFQ template already built, `FIT-OUT-SUPPLIER-RFQ-TEMPLATE.md`).
10. **Compare full landed costs and risk** (§7's framework) against the Australian benchmark from step 7 — not FOB price against Australian retail price.
11. **Sample/prototype critical or design-sensitive items** before any bulk order — already an existing repo requirement (`docs/architecture/PROCUREMENT-CHECKLIST.md` §1), reaffirmed.
12. **Independent factory inspection/QC** — engage a third-party inspector (§3.2's QIMA/SGS/Bureau Veritas category) regardless of whether an agent's own QC is used, as a genuine independent check, not a duplicated cost.
13. **Manufacture.**
14. **Consolidated shipment** (if multiple categories/factories are involved) — via the agent or freight forwarder, with marine insurance now explicitly included (§7's finding).
15. **Australian delivery/installation** — coordinated with the separately-engaged Australian trades for any item requiring licensed installation (electrical, plumbing, LEV connection).

**What changed from Anthony's original sketch, and why:** the sourcing-agent scoping conversation (step 8) is moved earlier — before individual factory pricing is sought — because an agent's own supplier network and category advice is more efficient to obtain first than to retrofit after direct factory contact has already happened. Everything else in Anthony's original sequence held up under this round's research and is preserved with only this one reordering plus the explicit addition of independent third-party inspection as its own numbered step (12) rather than an implicit part of "manufacture."
