# GRACE-R20-PAPER-SAFETY-NET: the weekly folder with a pocket per day

## 1. What it is, in one paragraph

Anthony's decision: each test day has a pocket inside a weekly folder. After the consult the midwife puts a copy of the client's referral in the pocket of the day of her TEST. If the client forgets her referral, the venue manager finds the copy in that day's pocket. The booking system holds the real record; the paper copy is only a safety net.

## 2. The set-up

| Item | Rule |
|---|---|
| Folder | One folder per week (Monday to Saturday). Six pockets, one for each test day, labelled with the date. Sunday is closed, so no pocket. |
| Rolling set | A consult can be up to 28 days before the test, so copies go into a folder up to 4 weeks ahead. Keep 5 folders live: this week and the next 4. |
| Index sheet | Inside the front cover of each folder, a day sheet with the booking reference number and test time of each copy filed. No client name on the sheet (see privacy). **Catherine to confirm.** |
| Home | A lockable cabinet or drawer in the consult room. A lockable unit and a copier or scanner are NOT IN REPO (cost and place to confirm). |
| Keys | The midwife on duty and the venue manager each hold a key. A spare key stays in a locked key box (NOT IN REPO). |

## 3. Who does what and when

| Step | Who | When | What |
|---|---|---|---|
| 1 | Midwife | End of each consult, "I need a referral" client | Writes the request in the booking system, marks "request issued". Makes one paper copy of the request. Writes the booking reference number on the copy (not the name on the outside). Files it in the pocket of the client's test date. |
| 2 | Midwife | Same, "I have a referral" client | Sees the original referral, checks it is complete, copies it, files the copy. Marks "outside referral seen". |
| 3 | Midwife | Same-morning consult | Files the copy straight into TODAY's pocket and gives the original request to the phlebotomist as usual. |
| 4 | Venue manager | 06:30 on a test day | Takes today's pocket out of the cabinet, checks it against the day's booking list, and keeps it in the reception desk drawer, out of sight of clients. Saturday: the senior staff member already rostered does this. |
| 5 | Venue manager | During the morning | If a client has no referral, uses section 6. Otherwise leaves the pocket alone. |
| 6 | Venue manager | After the last draw is done and the lab pickup is complete | Ticks each copy on the index sheet as "attended" or "no copy needed". Leaves the pocket tidy. |
| 7 | Venue manager | Before leaving (Monday to Friday 15:00; Saturday by the senior staff member) | End-of-day check (section 5). |
| 8 | Midwife | Before leaving at 16:00 | Locks the cabinet. |

## 4. What is copied, and what is not

| Copied | Not copied |
|---|---|
| The pathology request (referral) | Medicare card |
| Booking reference number added by hand | The consult notes (they stay in the clinical record, never in the folder) |
| | Any result |

Only the request is filed. No clinical notes ever go in the pocket.

## 5. End-of-day check

The venue manager (or Saturday senior staff member) does this every test day, in this order:

| # | Check | Done when |
|---|---|---|
| 1 | Count the copies in today's pocket and match them to the day's booking list | Every copy accounted for as attended, no-show or rebooked |
| 2 | Any copy for a client who attended: confirm the booking system shows "request issued" or "outside referral seen" | Ticked on the index sheet |
| 3 | Any copy for a no-show or rebooked client | Move the copy to the pocket of the new test date, or return it to the midwife's cabinet tray |
| 4 | Tomorrow's pocket: confirm the folder is in the cabinet | Seen |
| 5 | Cabinet locked, key returned | Initialled on the index sheet with the time |

A missing copy is reported the same day to the midwife and the manager (no blame; the system record is the master). If a copy is lost, the booking-system record still allows the test.

## 6. A client arrives without a referral

Order of steps, venue manager on the door (06:30 onwards):

| Step | Action |
|---|---|
| 1 | Look in the booking system for "request issued" or "outside referral seen". If it shows, she can be tested with the digital record. |
| 2 | Look in today's pocket for her copy (by booking reference number). If found, give it to the phlebotomist to travel with the sample. Whether the partner lab accepts a photocopy: NOT IN REPO (question 1). |
| 3 | If neither exists and her test pair is 08:40 or later, the midwife is on site from 08:00. If a consult block is free, offer a same-morning consult (A$130, GST-free, charged at the desk or already paid). She goes to the consult, then to her draw. |
| 4 | If her test pair is 07:00 to 08:15, or there is no free block: the midwife is not available in time. Offer the next free later pair that day if the midwife can see her first. If none, the booking terms apply: she rebooks (GRACE-R20-CANCELLATION.md). |
| 5 | If the midwife decides she should not have the test, the test does not go ahead. This is a clinical decision, recorded. |
| 6 | Say it kindly. The venue manager does not give medical advice. |

Rules the staff never break: no referral on file, no draw. Nobody writes or "backdates" a request. The venue manager never telephones a doctor to ask for one on her behalf without the client's consent. (Legal check: Catherine.)
