## Deliverable

### Part 1. The 15 questions (same list for every vendor)
1. Is all client data, including backups, stored in Australia? Name the data centres.
2. Does the system log every look at a record (who, what, when), including administrator access? Can anyone edit or delete the log?
3. Can we set these role levels? Midwives and phlebotomists open requests and records. The venue manager sees flags only. Service staff see nothing.
4. Can the two administrators (the owner, Anthony, and the hired venue manager) manage logins and settings without reading client records? Is each look still logged?
5. Does it run well on tablets in the collection rooms? What happens if the wifi drops?
6. Can we run with no paper folder at all? That means a scanned or photographed request, an on-screen signature for the Path B notice, and a filed copy of each request.
7. Can a midwife add a request but never delete one? Is a copy filed to the test-day record automatically?
8. Can the venue manager see a flag (for example, request missing) without any result or clinical note?
9. Can it record contact consent (call, voicemail, email, text) and a log line for each contact attempt (date, time, channel, outcome, midwife name)?
10. How often are backups made, how long are they kept, and how fast can you restore? When did you last test a restore?
11. Can we export every record in a standard format at any time, and when we leave, at no extra charge?
12. How do we remove a staff member's access, and how fast?
13. Is there two-step login and automatic log-out on tablets?
14. If there is a data breach, how fast do you tell us and what do you do? (Lawyer to check what GTT must do.)
15. What is the total cost? Set-up, price per user a month, storage, logs, support, contract length, and the price after year one.
