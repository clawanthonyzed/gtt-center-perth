# Naming Design-Exploration Assets

Two interactive visual design boards produced during the Elowen/Elowyn/Solena naming exploration (Claude Design "canvas" artifacts, exported from the founder's Cowork session). These are real, distinct creative work product — not duplicates of the markdown research documents, which describe and reference them but don't reproduce their visual content.

## Files

- **`Brand Worlds - Elowen vs Elowyn vs Solena.dc.html`** — Phase 1. A three-way comparative brand-world board (typography, palette, tone) for all three surviving candidates. Recommended "Build Elowen" at this stage, before the Solena Class 3 trademark finding existed. Synced from `github.md` (also in this export, not brought in as it's Cowork's own internal sync log, not project content): built from `README.md`, `docs/brand-guide.md`, and `docs/naming/CLAUDE-NAMING-INVESTIGATION.md`.
- **`Elowen vs Solena - Decision Board.dc.html`** — Phase 2. A two-way deep comparison (Elowyn already dropped at this stage) that rebuilt both Elowen and Solena's treatments from scratch and reversed Phase 1's call to "Build Solena."
- **`support.js`** — required runtime dependency for both `.dc.html` files (Claude Design canvas renderer). Both HTML files load it via a relative `<script src="./support.js">` — keep all three files in this same directory.

## How to view

Open either `.dc.html` file directly in a browser. They are self-contained aside from `support.js` (co-located here) and Google Fonts (loaded from `fonts.googleapis.com` — an internet connection is needed for the fonts to render as designed; the layout works without it, using fallback fonts).

## Relationship to the written record

Both boards are read, quoted, and critically evaluated in:
- `docs/naming/SOLENA-ELOWEN-STRATEGIC-HANDOVER-DECISION-AUDIT.md` (the audit that reconciles Phase 1's and Phase 2's opposite recommendations against the Solena Class 3 trademark finding)
- `docs/naming/NAMING-FINAL-COMPARISON.md` (the three-way comparison that gives Elowyn a fair Phase-2-equivalent written evaluation, since it never got its own board)
- `docs/naming/NAMING-DECISION-STATE.md` (current status — see that document for where the naming decision actually stands)

Neither board, nor any document referencing it, locks a final logo, palette, or type system for any candidate name — both are explicitly exploratory/comparative, per `docs/naming/NAMING-DECISION-STATE.md`'s "DO NOT START YET" list.
